Privacy Policy

Last updated: 24/08/2026

This privacy policy describes how MDA Digital SEO Automation (the "app") accesses, uses, and stores data when connecting to Google services on behalf of its user(s).

Who this app is for

This is a private, internally-used automation tool built with n8n. It is not distributed publicly and is not intended for use by the general public. It is used solely by MDA Digital to automate internal workflows.

What data this app accesses

This app requests access to the following Google services, only for the Google account(s) that explicitly authorize it:

  • Gmail — to send emails as part of automated workflow notifications and reports.
  • Google Sheets — to read and write data to specific spreadsheets used for storing and organizing automation results.
  • Google Drive — to create folders and save files generated by automated workflows.

How this data is used

Data accessed through these Google services is used exclusively to run the automation workflows described above — for example, saving research output to a file, appending results to a spreadsheet, or sending a notification email. Data is not sold, shared with third parties, or used for advertising purposes.

How this data is stored

Workflow data is processed by a self-hosted n8n instance controlled by MDA Digital. Files and records created as a result of these workflows are stored in the Google Drive/Sheets of the authorizing account itself, not on any third-party server beyond the infrastructure used to run the automation.

Data retention and deletion

Data is retained only as long as necessary for the workflows it supports. You may request deletion of any data associated with your account, or revoke this app's access at any time, via your Google Account permissions page.

Third-party sharing

This app does not share, sell, or transfer any Google user data to third parties. Data is used solely within the automated workflows described above.

Changes to this policy

This policy may be updated from time to time to reflect changes in how the app functions. The "Last updated" date at the top of this page will reflect the most recent revision.
